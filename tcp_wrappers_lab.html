📖 What are TCP Wrappers?

TCP Wrappers use two files to control which hosts can connect to network services:

/etc/hosts.allow — rules evaluated first. Matching connections are permitted.

/etc/hosts.deny — rules evaluated second. Matching connections are rejected.

Rule format: daemon : client
Example: sshd : 10.0.0.5
