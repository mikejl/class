Notation and glossary

Machine learning borrows symbols from statistics and calculus. This page lists every symbol used in the series, shows how to read the main equations out loud, and defines the key terms, each linked to the page where it is introduced.

Reading the equations

Math notation is compact, not mysterious. Each equation below is followed by a plain-English sentence you could say out loud.

ŷ = m·x + b

Linear regression (page 04). Read it as: The prediction equals the slope times x, plus the intercept.

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

Mean squared error (page 04). Read it as: Average the squared differences between the true and predicted values.

w ← w − α · ∂L/∂w

Gradient descent update (page 04). Read it as: Replace each weight with itself minus the learning rate times its gradient.

x_scaled = (x − μ) / σ

Standardization (page 05). Read it as: Subtract the mean, then divide by the standard deviation.

Loss = MSE + λ Σ wⱼ²

L2 regularization (page 07). Read it as: The error plus lambda times the sum of the squared weights.

σ(z) = 1 / (1 + e⁻ᶻ)

Sigmoid (page 08). Read it as: One over one plus e to the minus z; turns any score into a value between 0 and 1.

−[y log p + (1−y) log(1−p)]

Log loss (page 08). Read it as: If the label is 1, the loss is minus log p; if 0, minus log of one minus p.

precision = TP / (TP + FP)

Precision (page 09). Read it as: Of everything flagged, the share that was really positive.

recall = TP / (TP + FN)

Recall (page 09). Read it as: Of everything really positive, the share that was flagged.

hₜ = tanh(W·hₜ₋₁ + U·xₜ + b)

RNN update (page 13). Read it as: The new hidden state comes from the old state and the current input.
