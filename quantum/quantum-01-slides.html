01 · CLASSICAL BITS

A bit is always exactly 0 or 1

Every classical computer stores information as bits: a voltage that is either low (0) or high (1), never in between.

n bits

Can represent 2ⁿ different values. Four bits give 16 possibilities.

One at a time

Those bits hold only one of the 2ⁿ values at any moment.

n numbers

Describing the state of n bits takes just n numbers, each 0 or 1.

02 · THE QUBIT

Writing a qubit down: ket notation

|0⟩=10|1⟩=01
|ψ⟩=α|0⟩ + β|1⟩=αβ
rule: |α|² + |β|² = 1 · P(0) = |α|² · P(1) = |β|²

Amplitudes α and β are the numbers in front of each ket. Square them to get probabilities. Both nonzero means the qubit is in superposition.

03 · MEASUREMENT

Reading a qubit gives one ordinary bit

Random

Outcome 0 with probability |α|², outcome 1 with probability |β|².

Collapse

Afterward the qubit is in the state you saw. Measure again and you get the same answer.

Statistics

The amplitudes only show up as percentages across many freshly prepared qubits.

Common misconceptiona qubit does not let you read out "both 0 and 1." Every measurement returns exactly one bit.

04 · SCALING

Reality check: more qubits isn't infinite power

Readout limit

Measuring n qubits returns only n bits. Algorithms must make the right answer likely.

Decoherence

Noise turns superposition into ordinary 0s and 1s within microseconds to seconds.

Physical vs. logical

Reliable logical qubits are built from many noisy physical qubits.

Security linkrecent estimates put breaking RSA-2048 at under a million noisy physical qubits, far beyond today's machines.

WRAP-UP

Key takeaways

1

A classical bit is always 0 or 1; n bits need n numbers to describe

2

A qubit is written α|0⟩ + β|1⟩, a two-row column vector of amplitudes

3

Measuring gives one bit, chosen randomly with probability |amplitude|²

4

n qubits need 2ⁿ amplitudes, which overwhelms classical simulation past ~50 qubits
