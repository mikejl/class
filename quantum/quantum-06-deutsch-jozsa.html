One question instead of many

The Deutsch-Jozsa algorithm (1992) was the first proof that a quantum computer can solve a problem with certainty using exponentially fewer steps than any classical computer. The problem itself is artificial, but the technique of superposition, phase, and interference reappears in every major quantum algorithm, including Shor's.

01 · The problem

Constant or balanced?

Someone hands you a sealed box, called an oracle, that computes a function f(x). The input x is n bits, and the output is a single bit. You're promised the function is one of two kinds:

Oracle — a black-box function you can call but not open. Algorithms are compared by how many times they must call (query) it.
CONSTANT
Returns the same output for every input: always 0, or always 1.
BALANCED
Returns 0 for exactly half the inputs and 1 for the other half.

Your job: figure out which kind it is, with certainty, using as few queries as possible.

02 · The classical way

Query inputs one at a time

Try it: crack the mystery box classically

Click inputs to query the box. Stop as soon as you're certain. Seeing a 0 and a 1 proves "balanced," but proving "constant" means checking more than half.

03 · The quantum way

Query every input at once, then interfere

The quantum circuit puts all n input qubits into superposition with Hadamards and feeds them to the oracle once. Using a helper qubit in the |−⟩ state, the oracle marks each input with a sign, (−1)f(x). This trick is called phase kickback. A final round of Hadamards makes those signs interfere.

Phase kickback — when the oracle flips a helper qubit that is in state |−⟩, the helper stays |−⟩ and a minus sign lands on the input instead. The function's answer becomes a phase rather than a bit.

Try it: run Deutsch-Jozsa on the same mystery box

Uses the box from section 02. One query, then a measurement. All zeros means constant; anything else means balanced.

04 · Why it works

The all-zeros amplitude is an average of signs

After the last Hadamards, the amplitude of the all-zeros outcome works out to the average of every sign:

amplitude of|0…0⟩=(1/2ⁿ) Σx (−1)f(x)
constant: all signs equal → average is ±1 → always measure 0…0
balanced: half +, half − → they cancel to 0 → never measure 0…0

That's interference from page 02 at a larger scale. Wrong answers cancel, right answers reinforce, and a single measurement settles the question.

05 · Why it matters

A toy problem with a serious lesson

Nobody needs to know whether a function is constant or balanced. A classical computer that's allowed a tiny chance of error can also solve it with just a few random queries. Deutsch-Jozsa matters because it showed, cleanly and provably, that the quantum toolkit (superposition, phase, interference) could do something classical computing can't match with certainty.

The road to Shor: Simon's algorithm (1994) used the same pattern to find a hidden repeating structure in a function. Peter Shor generalized that idea to find the hidden period of modular exponentiation, and that's the algorithm that breaks RSA (page 08).
